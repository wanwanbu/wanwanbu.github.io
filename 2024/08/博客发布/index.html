博客发布

2024年08月21日 blog hugo

思路

  • 分别把主文件、静态文件、评论系统分别分三个仓库部署。
  • 主文件仓库属于私有的不公开仓库。使用GitHub Actions自动部署到静态文件仓库
  • 静态文件是要公开才能使用GitHub panges
  • 评论系统也是属于公开的仓库

开始部署

1.创建私有仓库

2. 获取token

如果设置了token过期时间到时候还要在GitHub上延长过期时间继续使用。token只显示一次记得复制下来，等下把token值添加到环境变量中。

3.token添加到环境变量

4.回到本地主文件

在主文件中创建**.github/workflows/hugo.yaml**而hugo.yaml文件下复制下面内容

name: deploy

# 代码提交到main分支时触发github action
on:
  push:
    branches:
      - main

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
        - name: Checkout
          uses: actions/checkout@v4
          with:
              fetch-depth: 0

        - name: Setup Hugo
          uses: peaceiris/actions-hugo@v3
          with:
              hugo-version: "latest"
              extended: true

        - name: Build Web
          run: hugo -D

        - name: Deploy Web
          uses: peaceiris/actions-gh-pages@v4
          with:
              PERSONAL_TOKEN: ${{ secrets.你的token变量名 }}
              EXTERNAL_REPOSITORY: 你的github名/你的仓库名
              PUBLISH_BRANCH: main  #选择的分支
              PUBLISH_DIR: ./public
              commit_message: auto deploy

创建静态仓库

如果你需要分支创建时候勾选README。然后在仓库中点击Branches跳转到下面图的页面。

使用git发布

发布前还需要在本地仓库一个排除上传的文件.gitignore

#.gitignore内容
.hugo_build.lock
hugo.exe
public
resources

#使用git上传命令
git init
git add .
git branch -M main
git remote origin 私有仓库地址
git push -u origin main

等到GitHub 自动部署到静态仓库时。回到静态仓库开启GitHub panges。

在浏览器中打开用户名.github.io成功就表示你的网站部署上线。如果失败检查私有仓库中的，Actions查看报错信息。

评论系统部署

  1. 基于 Github 的 Issues 或 Discussions 存储的评论系统，如 Giscus、Utterances、Gitment 等。
  2. 基于 Serveless 平台云数据库免费额度部署的评论系统，如 Waline、Twikoo 等，都可以使用 云开发 / Vercel / 私有服务器 一键部署。

我使用giscus,为什么选择它？1.不需要购买服务器(是没闲钱能白嫖就白嫖)。2.迁移评论系统方便。3.产品迭代较快。

缺点也是必须有的,它必须是GitHub OAuth 授权登录后才可以评论。

创建github评论仓库

在 Github 上创建一个 blog-comments(当然仓库名字可以自己取) 仓库，用于存储博客的评论。

打开仓库设置settings–>General–>features–>勾选Discussions

第一次启用Discussions时需要点击下面set up discussions按钮，为讨论组设置欢迎用语和讨论规则。设置完成后点击star discussions按钮就完成。

安装Giscus App

打开一个新页面,打开Giscus App地址,选择install按钮。

我是选择Only setect repositories—>选择你要授权仓库如(我刚刚创建的blog-comments仓库)

Giscus设置

打开Giscus中文官网，按页面向导依次设置评论功能的语言github存储和个性化配置。

我的配置如下：

配置完成后就会生成一个javascript脚本。所以的操作都是为了生成这个脚本。把脚本保存好。

<script src="https://giscus.app/client.js"
        data-repo="仓库地址"
        data-repo-id="仓库id"
        data-category="Announcements"
        data-category-id="分类id"
        data-mapping="pathname"
        data-strict="0"
        data-reactions-enabled="1"
        data-emit-metadata="0"
        data-input-position="top"
        data-theme="light_tritanopia"
        data-lang="zh-CN"
        data-loading="lazy"
        crossorigin="anonymous"
        async>
</script>

查看hugo主题配置文件是否有giscus:。如果有就直接配置主题配置文件。

   comments:
        enabled: true #开启评论
        provider: giscus #使用什么系统做评论
        giscus:
            repo: "" #仓库地址
            repoID: "" #仓库id
            category: "Announcements" #分类名
            categoryID: "" #分类 ID
            mapping: "pathname" #用于映射评论到不同的页面
            reactionsEnabled: 1 #表示启用反应功能
            emitMetadata: 0 #表示不启用元数据传输
            lang: "zh-CN" #语言
            inputPosition: "top" #表示评论输入框显示在页面顶部
            theme: "light_tritanopia" #是一个有效的 Giscus 主题
            loading: "lazy" #表示延迟加载评论

说明你已经成功了。

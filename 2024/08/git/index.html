git介绍和使用

git的三个区域

  • 工作区：处理工作的区域(红色)
  • 暂存区：git提交缓存区或者叫临时存放区域(绿色)
  • 版本库：git生成的版本或者叫最终存放区域(黄色)

git使用

鼠标右键出现bash here说明你成功安装了了git。

配置个人信息

git安装完成需要做的第一件事是配置用户名和邮箱，而配置文件存放三个位置。

  1. 当前项目配置文件路径：.git/config
#直接在当前项目输入下面命令
git config --local user.name "你的用户名"
git config --local user.email "你的邮箱"
  1. 全局配置文件路径：~/.gitconfig
#一般使用全局配置以后使用git就不需要在配置一次
git config --global user.name "你的用户名"
git config --global user.email "你的邮箱"

3.系统配置文件路径：/etc/.gitcongit

git config --system user.name "你的用户名"
git config --system user.email "你的邮箱"
#注意这个需要超级管理员权限。

配置完成查看是否配置成功命令：git config –list。出现user.name “你的用户名"和user.email “你的邮箱”，说明配置成功了。按q退出git config –list命令。如果修改就修改配置文件或者重新执行命令。

初始化空的git仓库

git检查文件

git status 如果有文件是红色说明文件在工作区。

git管理文件

git add 文件名称或者目录或者使用git add . 命令意思是将工作区一个或者全部提交到暂存区里。

git生产版本

git commit -m “自己取的版本名称” 命令意思是将暂存区的文件提交到版本库里。
